# Nintendo Swith Game Radar

برنامه، قیمت و موجودی بازی‌های Nintendo Switch را از فروشگاه‌های تعریف‌شده در پوشهٔ `scripts` جمع‌آوری می‌کند و در قالب کارت‌های بازی نمایش می‌دهد.

## استفاده

### راه‌اندازی روی ویندوز، macOS و لینوکس

1. Python 3.10 یا جدیدتر را نصب کنید و ترمینال را در پوشهٔ پروژه باز کنید. همهٔ مسیرهای این راهنما نسبت به همین پوشه هستند؛ مسیر نصب پروژه ثابت نیست.
2. یک محیط مجازی بسازید:

   ```text
   python -m venv .venv
   ```

3. محیط مجازی را فعال کنید:

   ```text
   Windows PowerShell: .venv\Scripts\Activate.ps1
   Windows Command Prompt: .venv\Scripts\activate.bat
   macOS / Linux: source .venv/bin/activate
   ```

   اگر فرمان `python` موجود نیست، در macOS یا لینوکس از `python3` و در Windows از `py` استفاده کنید.

4. وابستگی‌ها را نصب کنید و برنامه را اجرا کنید:

   ```text
   python -m pip install -r requirements.txt
   python app.py
   ```

مرورگر به‌طور خودکار باز می‌شود. اگر باز نشد، آدرس `http://localhost:5050` را وارد کنید. برنامه هنگام اجرا هیچ فروشگاهی را خودکار به‌روزرسانی نمی‌کند. برای انتخاب فروشگاه‌ها و شروع به‌روزرسانی، **Run now** را بزنید؛ انتخاب‌ها برای نمایش کاتالوگ و اجراهای بعدی ذخیره می‌شوند.

برای توقف برنامه، در ترمینال کلیدهای `Ctrl+C` را بزنید.

### اجرای یک فروشگاه به‌تنهایی

از پوشهٔ پروژه، نام اسکریپت موردنظر را اجرا کنید؛ مسیرهای زیر نسبت به پوشهٔ پروژه هستند. در صورت نیاز `python` را با `python3` جایگزین کنید:

```text
python scripts/psparsi.py
python scripts/westgamestore.py
```

## راهنمای توسعه‌دهنده

### ساختار پروژه

- `app.py` — سرور Flask و API برنامه.
- `scheduler.py` — اجرای دوره‌ای و دستی اسکریپت‌ها و ثبت گزارش به‌روزرسانی.
- `db.py` — ذخیره و گروه‌بندی بازی‌ها در SQLite.
- `scripts/` — اسکریپت‌های دریافت اطلاعات فروشگاه‌ها.
- `scripts/_scraper_utils.py` — ابزارهای مشترک استخراج HTML، عنوان و تصویر.
- `templates/` و `static/` — صفحه، ظاهر و جاوااسکریپت برنامه.
- `data/timeline.db` — پایگاه دادهٔ بازی‌ها.
- `data/image_cache/` — تصویرهای ذخیره‌شدهٔ محلی.
- `logs/` — گزارش اجرای هر اسکریپت.

### افزودن یا ویرایش اسکریپت فروشگاه

فایل هر جمع‌آورنده را مستقیماً در `scripts/` بسازید. زمان‌بند همهٔ فایل‌های `.py` این پوشه را خودکار پیدا می‌کند؛ فایل‌هایی که نامشان با `_` شروع می‌شود، مانند `_scraper_utils.py`، اجرا نمی‌شوند.

اسکریپت باید محصولات را به قالب مورد استفادهٔ `db.upsert_item` تبدیل کند. فیلدهای اصلی:

```python
{
    "source": "store_name",
    "title": "Game title",
    "text": "Price or short details",
    "link": "https://store.example/product",
    "condition": "new",       # یا used
    "in_stock": True,
    "platform": "Switch1",    # یا Switch2
    "image_url": "https://store.example/image.jpg",
}
```

از لینک ثابت محصول به‌عنوان `link` استفاده کنید تا هر محصول در هر فروشگاه تکراری ذخیره نشود. نام `source` را معمولاً به‌شکل `<نام‌اسکریپت>_nintendo` بگذارید تا انتخاب فروشگاه خودکار کار کند. اگر از چند منبع داخلی استفاده می‌کنید یا نام منبع با این الگو فرق دارد، آن را به `SITE_SOURCES` در `db.py` اضافه کنید. از توابع مشترک `_scraper_utils.py` برای تجزیهٔ HTML، پاک‌سازی عنوان و استخراج تصویر استفاده کنید.

### بررسی اجرا و پیکربندی

- اجرای کامل یک چرخه بدون راه‌اندازی وب‌سرور (از پوشهٔ پروژه): `python scheduler.py`
- گزارش هر سایت: `logs/<نام‌اسکریپت>.py.log`
- پورت پیش‌فرض: `5050`؛ با متغیر محیطی `NOTIFIER_PORT` قابل تغییر است.
- میزبان پیش‌فرض: `0.0.0.0`؛ با `NOTIFIER_HOST` قابل تغییر است.
- مسیر پایگاه داده را می‌توان با `NOTIFIER_DB` عوض کرد.
- باز شدن خودکار مرورگر را با `NOTIFIER_OPEN_BROWSER=0` غیرفعال کنید.
- زمان‌بند برای هر اسکریپت حداکثر ۱۲۰ ثانیه صبر می‌کند (`SCRIPT_TIMEOUT` در `scheduler.py`).

وابستگی‌های پایتون در `requirements.txt` ثبت شده‌اند. بخش عمدهٔ دریافت صفحات با کتابخانه‌های استاندارد Python انجام می‌شود.
